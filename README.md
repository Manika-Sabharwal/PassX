🔐 PassX — Secure Password Manager

PassX is a lightweight and secure password manager built using HTML, CSS, JavaScript, and Firebase. It allows users to safely store, manage, and access their credentials in a clean and user-friendly interface.
🚀 Live Demo
https://passx-2b164.web.app

📌 Features
1. 🔑 User Authentication : Secure Login & Signup using Firebase Authentication
2. 🗂️ Password Management : Store website credentials (URL, username, password) View saved passwords in a structured card layout
3. ✏️ CRUD Operations : 
    Add new passwords
    Update existing entries (if implemented)
    Delete entries with confirmation (if implemented)
4. 🔍 Search Functionality (if implemented) : Quickly find saved credentials
5. 👁️ Show/Hide Password : Toggle visibility for better usability
6. 📋 Copy to Clipboard : Copy passwords instantly
7. 🎨 Modern UI : Clean and responsive design

🛠️Tech Stack
1. Frontend: HTML, CSS, JavaScript
2. Backend (BaaS): Firebase
3. Database: Firebase Realtime Database / Firestore
4. Authentication: Firebase Auth
5. Hosting: Firebase Hosting
